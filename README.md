# 📚 Aplikasi Data Buku Perpustakaan

Aplikasi pengelolaan data buku perpustakaan berbasis **JSON API dan CRUD** dengan fitur login admin, dashboard statistik, serta export Excel dan PDF.

## ✨ Fitur
- Login admin
- Dashboard statistik
- Tambah, tampilkan, edit, dan hapus data buku (CRUD)
- JSON API untuk data buku
- Export data ke Excel dan PDF
- Database MySQL

## 🛠️ Teknologi
- PHP
- MySQL
- HTML, CSS, dan JavaScript
- XAMPP

## 🚀 Cara Menjalankan
1. Install dan jalankan Apache serta MySQL melalui XAMPP.
2. Letakkan folder proyek di `C:\xampp\htdocs\perpus_api`.
3. Buka phpMyAdmin.
4. Buat database sesuai konfigurasi pada file koneksi.
5. Import file `perpus_api.sql`.
6. Sesuaikan konfigurasi database di file koneksi.
7. Buka `http://localhost/perpus_api/login.php` di browser.
8. Login menggunakan akun admin yang sudah terdaftar di database.

## 🗄️ Database
File database tersedia di [`perpus_api.sql`](perpus_api.sql).
